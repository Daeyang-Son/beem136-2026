# BEEM136 Research Methods I: class repository, 2026

This repository is a shared sandbox for BEEM136 at the University of Exeter.

Each student adds one file to the `students/` folder, via a fork and a pull request:

1. Fork this repository on GitHub.
2. Clone your fork: `git clone https://github.com/YOUR-USERNAME/beem136-2026.git`
3. Copy the template: `cp students/_template.md students/YOUR-USERNAME.md`, and fill it in.
4. `git add`, `git commit`, and `git push` to your fork.
5. Open a pull request back to this repository.

Everything here is public, so only write what you are happy to share.
